How this scanner estimates timing

1. BTC support is estimated from recent hourly and four-hour candle lows.

2. Downside pressure is assessed using multi-timeframe trend, RSI, volume, candle momentum and order-book imbalance.

3. ETA is estimated using the distance to a level and recent ATR-based movement speed. If price is moving sideways or the signal is weak, the scanner displays “Uncertain”.

4. Altcoin EP, SL and targets are calculated from current price, nearby support/resistance and volatility. Targets use risk multiples, not guaranteed profit levels.

5. The London and New York session labels use local timezone clocks, so daylight-saving changes are handled automatically.

Important: This is an educational analysis tool, not financial advice. No scanner can reliably predict every sudden BTC move. Backtest and paper trade before risking money. No orders are executed by this page.
