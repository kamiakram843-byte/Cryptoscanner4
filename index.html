🧠 Model methodology

BTC-led forecast
BTC direction is estimated first from hourly momentum, EMA trend, RSI and volatility. Altcoin returns are then estimated using rolling BTC beta and coin-specific residual momentum.
Market confirmation
Futures volume, spot price confirmation, funding rate, RSI and EMA trend contribute to the signal score. Funding is treated as context, not a directional guarantee.
Entry and targets
Entry uses a breakout trigger based on recent hourly highs/lows. Stop distance uses ATR. TP1, TP2 and TP3 target 1R, 2R and 3R respectively.
Risk controls
Signals are suppressed when BTC is neutral or forecast confidence is weak. A forecast horizon is not an exact arrival time. Backtesting is needed before real trading.

⚠️ Data and risk notes

This application uses public Binance REST endpoints. It does not use private accounts or place orders. A BTC beta is historical sensitivity, not a promise that an altcoin will move by the same multiple. The confidence score is a heuristic ranking score, not a statistically calibrated probability. This version does not claim to detect actual whale wallets or liquidation clusters. All listed pairs are discovered dynamically; deep analysis is limited by the selected scan limit and API rate limits. Always independently verify the market and levels before trading.
